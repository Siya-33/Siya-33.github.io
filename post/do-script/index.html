用脚本在Directory Opus中解放双手

2025-01-11
阅读时长: 1 分钟
437字

我们在日常处理文件的过程中经常会遇到一些重复的劳动，用命令虽然快但有学习成本，而且始终没有图形界面的交互直观。今天稍微学习了下自定义脚本的步骤，记录下方便以后有人需要。当然，我估计才发挥出 Directory Opus 百分之十的功能，更多的还是自己去挖掘吧。

譬如把封面压缩成webp格式,或者是扩充背景这类重复操作我就可以一键完成了

现在介绍下具体操作。

依次点击设置-自定义工具栏和热键-用户命令-新建，我这里把类型改为了MS-DOS批处理功能

1
2

@nofilenamequoting
magick "{filepath}" -quality 80 "{filepath|noext}.webp"

点击确定后，别关闭自定义窗口，把脚本拖拽到想要的区域即可。

之后只要选中想要的图片再点击按钮，当然想要更加有条理只要在代码上缝缝补补就可以了。

需要动态的参数输入也很简单，以扩充背景为例

Resize

1
2
3
4

@set w={dlgstring|Enter Width (w)|1920}
@set h={dlgstring|Enter Height (h)|1080}
@nofilenamequoting
ffmpeg -i "{filepath}" -vf "scale=w={$w}:h={$h}:force_original_aspect_ratio=decrease,pad={$w}:{$h}:(ow-iw)/2:(oh-ih)/2:black" "{filepath|noext}_resized.jpg"

另外论坛也有很多大神分享的脚本代码，可以去官网上找。我当时下了这个软件也是一头雾水，建议慢慢按需添加功能，适合自己的才是最好的
