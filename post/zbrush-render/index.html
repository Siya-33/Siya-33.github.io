Zbrush渲染基本流程

封面有点欺诈是SP上了材质后的渲染图。姑且记录一下Zbrush渲染的过程，主要参考了Orb的渲染教程

Rock Sculpt
岩石雕刻练习
https://www.artstation.com/artwork/dKvxRK

前期准备

Draw 选项卡下将焦距设置为85mm，视情况设置Align To Object

Render - Render Properties下激活AO

调整Shadow

调整灯光分别渲染 Keylight 和 RimLight

主光用 Orb Clay，补光用 Basic Material

分别导出 Shaded、Depth、Mask，由于深度图和Mask一致，最终得到4张图，保存为PSD格式方便处理

PS合成

对补光Ctrl+L色阶调整，提高对比度，之后擦除不想让边缘光产生的位置

此时的边缘光有较多锯齿，导入Mask，将通道作为选区
Ctrl+Shift+C→隐藏Mask图层→Ctrl+V，得到一张背景透明的渲染主体A

新建合适的背景图层并与A合并

将Depth复制至新通道，以它为源对A做镜头模糊

放两张效果图
